# Sementes Kids

Site do Kit Bíblico Infantil Sementes Kids, reproduzido a partir do arquivo fornecido, mantendo o conteúdo, o visual e as interações originais.

## Tecnologias

HTML, CSS e JavaScript estáticos, imagens WebP e hospedagem Netlify. Não há dependências de pacotes nem etapa de compilação. O diretório publicado é `public`, configurado em `netlify.toml`.

## Executar localmente

Na raiz do projeto, execute `python3 -m http.server 8080 --directory public` e abra `http://localhost:8080`.

As fontes do Google, os serviços de rastreamento e o checkout preservados do original dependem de conexão à internet e dos respectivos serviços externos.
